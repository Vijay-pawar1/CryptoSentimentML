# CryptoSentimentML

## Cryptocurrency Sentiment Analysis and Machine Learning-Based Price Signal Prediction

CryptoSentimentML is a final-year B.Sc. project that combines cryptocurrency market data, technical indicators, and sentiment analysis with machine learning to predict short-term cryptocurrency price direction.

The initial system focuses on **BTC/USDT using 1-hour market data** and produces three possible signals:

* BUY
* HOLD
* SELL

The project will be developed in stages, beginning with historical market-data analysis and later adding sentiment analysis, machine learning, backtesting, and paper trading.

---

## Research Question

**Does adding cryptocurrency sentiment information improve short-term directional prediction compared with using market and technical indicators alone?**

## Methodology

The project will use chronological time-series validation rather than randomly shuffling historical observations.

Special attention will be given to:

* Data leakage
* Overfitting
* Time-series validation
* Class imbalance
* Transaction costs
* Slippage
* Model evaluation
* Reproducibility

Future information must not be used to generate features for a historical prediction.
